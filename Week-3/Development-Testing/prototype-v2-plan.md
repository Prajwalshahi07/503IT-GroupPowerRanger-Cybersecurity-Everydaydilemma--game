There will be total 3 missions in the game. Once registered the first mission will be unlocked. Only after answering the first mission the user can unlock the other missions.

Each mission is based on a realistic phishing scenario commonly experienced by  university students.

mission 1 focuses on an urgent assignment re-upload phishing scam. 

Mission 2 focuses on a fake university IT password reset scam. 

Mission 3 focuses on a fake tuition fee refund phishing scam. 


Each mission presents the player with a visual phishing scenario using realistic images and interfaces. 

Every scenario is designed to simulate real cyberattack techniques such as urgency, fear, and fake authority. 

 Players are required to choose between three possible actions in every mission. 

 
 
The decision-making system evaluates whether the player’s action is safe, risky, or dangerous.

Correct decisions reward the player with positive points and educational feedback. 

 Risky or dangerous decisions reduce the player’s score and explain the consequences of phishing attacks.

 
 
 The game provides instant feedback after every decision to reinforce cybersecurity learning. 

 Feedback messages explain phishing red flags such as suspicious links, fake domains, and urgency tactics. 
 
 The score system tracks the player’s cybersecurity awareness performance throughout the game. 
 
The player’s total score is updated dynamically after every mission choice. 

 After completing a mission, the player unlocks the next stage of the phishing awareness challenge. 
 
 The game progression system encourages continuous learning through mission completion. 
 
 
A final results screen summarizes the player’s performance at the end of all missions.

Different ending outcomes are displayed depending on the player’s final cybersecurity score. 

 High scores result in a “Safe Semester Achieved” ending and phishing defender recognition. 
 
 Lower scores result in warnings about compromised cybersecurity awareness. 
 
The game combines education and gamification to improve student engagement in phishing awareness training.

The visual design uses a cyberpunk neon theme to create an immersive cybersecurity atmosphere. 

The project is developed using HTML for structure, CSS for styling, and JavaScript for game logic.
